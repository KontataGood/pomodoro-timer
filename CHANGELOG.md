# Changelog

All notable changes to this project are documented in this file.

## [0.2.1] - 2026-10-21

### Added
- Session history stored locally in an SQLite database.
- History dialog displaying completed focus and break sessions.
- Session timestamps and durations.

### Tests
- Added automated tests for session history storage and retrieval.

## [0.2.0] - 2026-10-20

### Added
- Configurable focus, short break, and long break durations.
- Russian and English localization.
- Multiple color themes.

### Fixed
- Preserve remaining time when switching timer modes.

## [0.1.0]

- Initial release.
