# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-11-01

### Added
- Cross-platform desktop application support for Windows and macOS.
- Pomodoro timer with configurable focus, short break, and long break durations.
- Session history stored locally in an SQLite database.
- History dialog displaying completed focus and break sessions.
- Session timestamps and durations.
- Statistics for completed sessions.
- System tray integration.
- Application startup on system login.
- Russian and English localization.
- Multiple color themes.
- Custom application icons for Windows and macOS.

### Improved
- Updated sidebar navigation and active page styling.
- Improved application resource handling.
- Added platform-specific application build configurations.
- Improved Windows application packaging with PyInstaller.

### Fixed
- Preserve remaining time when switching timer modes.
- Improved application startup and resource loading.

### Tests
- Added automated tests for timer functionality.
- Added automated tests for session history storage and retrieval.
